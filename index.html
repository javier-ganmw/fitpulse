Setting up Google Health API

You need a free Google Cloud project with the Health API enabled. Takes about 5 minutes.

1
Create a Google Cloud project
Go to console.cloud.google.com, create a new project (or use an existing one), and enable the Google Health API from the API Library.
2
Configure OAuth consent screen
Go to APIs & Services → OAuth consent screen. Set user type to External. Add these scopes on the Data Access page:

googlehealth.activity_and_fitness.readonly
googlehealth.health_metrics_and_measurements.readonly
googlehealth.sleep.readonly
googlehealth.profile.readonly

Then add your Google account email as a Test User on the Audience page.
3
Create OAuth credentials
Go to APIs & Services → Credentials → Create Credentials → OAuth client ID.

Set type to Web application. Add this as an Authorised redirect URI:

Copy your Client ID and Client Secret.
4
Paste into FitPulse and connect
Close this dialog, paste both values into the form, and click Connect. You'll be redirected to Google to authorise, then land on your dashboard.

Privacy: Your Client Secret and access token are stored only in sessionStorage and cleared when you close the tab or disconnect. No data is ever sent to any server other than Google's.
